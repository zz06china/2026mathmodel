# 问题三运行说明

## 环境

- Python 3.11 或更高版本
- 安装依赖：`pip install -r requirements.txt`
- 保持 `C题/附件`、`C题_Q1_最终模型`、`C题_Q2_最终模型` 与本目录处于同一上级目录

## 复现顺序

1. 运行 `python q3_final.py`，生成最终结果 `result3.xlsx` 和校验文件 `q3_metrics.txt`。
2. 运行 `python q3_update_ablation.py`，复现 6:00、12:00、18:00 全部八种更新组合的消融结果。
3. 运行 `python build_q3_model_report.py`，由结果表和指标文件刷新 `第三问最终模型.md`。
4. 运行 `python build_q3_model_docx.py`，生成含 Word 原生公式的模型文档。

正式模型采用四个发布时刻、28 天历史净负荷残差窗口、分阶段分位数 $(0.80,0.70,0.70,0.70)$ 和 5400--6600 kWh 终端 SOC 带状约束。所有当日决策只使用当时及此前可获得的信息。
