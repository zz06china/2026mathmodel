# 问题四运行说明

## 环境

- Python 3.11 或更高版本
- 安装依赖：`pip install -r requirements.txt`
- 保持 `C题/附件`、`C题_Q1_最终模型`、`C题_Q2_最终模型`、`C题_Q3_最终模型` 与本目录处于同一上级目录

## 复现顺序

1. 运行 `python q4_final.py`，生成正式因果结果 `result4-2.xlsx`、`result4-3.xlsx`、汇总表及 `q4_metrics.txt`。
2. 运行 `python generate_q4_figures.py`，生成两张 SVG 矢量图。
3. 运行 `python build_q4_model_docx.py`，生成含 Word 原生公式和图形占位符的文档。
4. 运行 `powershell -ExecutionPolicy Bypass -File finalize_q4_doc.ps1`，插入 SVG 并导出最终 PDF。

正式结果采用因果电价预测；`q42_perfect`、`q43_perfect` 只是不使用于答题策略的完全信息下界，`q42_fixed`、`q43_fixed` 是保持原购电策略不变的动态电价反事实。问题4-3的价格收缩权重 0.5 由 1 月校准样本确定，2--12 月仅作正式评估。
